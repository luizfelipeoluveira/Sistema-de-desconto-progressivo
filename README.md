# 💵 Sistema de Desconto Progressivo

Sistema desenvolvido em **Python** para calcular descontos progressivos de acordo com o valor total da compra do cliente.

## 📌 Sobre o projeto

O programa recebe o valor de uma compra inserida pelo usuário e aplica diferentes porcentagens de desconto conforme a faixa de preço definida no programa.


## ⚙️ Funcionamento

O usuário informa o valor da compra e o sistema verifica em qual faixa de preço o valor se encontra.

Após identificar a faixa correspondente, o programa calcula o desconto e apresenta o resultado ao usuário.
